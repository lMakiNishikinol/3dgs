# 前端逻辑与页面规划

## 四个主板块

1. 效果展示：搜索、推荐模型、分页浏览、进入案例详情。
2. 上传视频：相册/拍摄选择、素材确认、公开权限、前端进度状态；真实上传暂不执行。
3. 我的订单：分页查询重建任务，展示等待、处理中、完成、失败状态。
4. 个人主页：用户资料、模型统计，以及收藏、消息、邮箱、客服、协议、反馈和关于页面入口。

## 二级页面关系

- 模型卡片 → 案例详情 → 创作者主页。
- 我的收藏 → 分页模型列表 → 案例详情。
- 他人主页 → 按 ownerId 分页查询公开模型 → 案例详情。
- 个人主页 → 消息通知 / 编辑资料 / 邮箱管理 / 客服 / 协议 / 反馈 / 关于。
- 上传确认 → 后端创建上传任务 → 对象存储直传 → 完成回调 → 订单页跟踪重建状态。

## 分页与无限数据

前端不直接访问数据库。页面通过 service 请求后端分页 API，并只在 React state 中保存当前页 items。响应包含 page、pageSize、total、totalPages、hasNext。这样数据库可持续增长，前端内存不会随总模型数线性增加。页码控件最多显示 5 个相邻页码，支持上一页、下一页和指定页跳转。

当前 src/services/request.ts 中 API_BASE_URL 为空时使用确定性的 mock 数据；接入后端时填写 HTTPS 基址即可自动切换真实 REST API。
